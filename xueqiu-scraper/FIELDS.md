# 雪球数据字段说明(data/xueqiu_*.csv)

导师定的**重要字段**已排在最前:`post_id · user_id · 标题 · 正文 · 评论`。

| 列名 | 中文 | 说明 |
|------|------|------|
| **post_id** | 帖子ID | 唯一,去重键 |
| **user_id** | 用户ID | 发帖人ID(-1 多为官方资讯号) |
| author | 用户名 | 发帖人昵称 |
| created_at | 发帖时间 | YYYY-MM-DD HH:MM:SS |
| **title** | 标题 | 雪球多数帖无独立标题,常为空(正文才是主体) |
| **text** | 正文 | 帖子正文(**100% 有值**) |
| **reply_count** | 评论数 | 该帖评论条数(评论**内容**未抓,如需另说) |
| like_count | 点赞数 | |
| retweet_count | 转发数 | |
| view_count | 阅读数 | |
| symbol / stock_name | 股票代码/名称 | 如 SZ300301 / ST长方 |
| source | 发布来源 | 如 网页/雪球App |
| url | 帖子链接 | 可回溯核对 |
| truncated | 正文是否被截断 | 1=长帖被截,需补全 |
| fav_count | 收藏数 | |
| crawl_time | 采集时间 | |

> **说明**:本批为雪球公开接口**前 ~1000 条/只**(平台硬顶,到不了 2020),覆盖近端(23~26 年)。
> **评论内容**:当前只存"评论数",未抓评论正文;导师若要评论正文,可加一步逐帖抓取(会多不少请求)。
