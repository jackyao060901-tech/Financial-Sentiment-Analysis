## 二、关键发现:为什么诺泰/逸飞"只到 2020-06 / 2022-06"

**不是被封,是它们的股吧本来就没有更早的帖子。**
- 实测:ST诺泰第 292 页(2020-06-17)是**最后一页**,再深即空;ST逸飞第 94 页(2022-06-24)是最后一页,再深即空。
- 同时对照 ST和科第 1 页正常返回 → **IP 没被封**,空页 = 到底。
- 原因:两者是**科创板股票、上市晚**(诺泰生物 2021 年、逸飞激光 2023 年上市),股吧从上市前打新讨论才开始,**2020 年以前根本不存在帖子**。
- 结论:**它俩现有的 2 万余 / 7 千余条,就是其股吧的完整历史**,已采全,无法更早。

因此:**3 只(长方/和科/得润)回溯到 2020 之前,2 只(诺泰/逸飞)采到其股吧起点——5 只的完整可得历史全部到手。**

## 三、方法:采用老师的多线程打法(已整合进本仓库)

之前单线程死磕一只、翻 150 页就被机房 IP 限流。改用**老师 `guba-scraper` 的可取之处**(整合为 `scripts/collect_st_guba.py`)后,顺利采到 12 万条未被硬封:

1. **多线程跨 5 只股票并行**:分散访问、像浏览多个吧,而非死磕一只 → 抗封。
2. **拟人延时** 页间 3–5s。
3. **SQLite + post_id 主键去重**:幂等,反复跑不重复。
4. **按已有行数断点续采** + **自动循环**(`scripts/run_st_loop.sh`:采→导出→提交→冷却→续采)。
5. **停止条件**:回溯到 2020 或连续空页(到底/限流)。

> 说明:本沙盒是机房 IP,东财对它比住宅 IP 严;多线程分散访问是这次没被硬封的关键。
> 在住宅 IP / 梯子上跑同一脚本更稳(老师实测住宅 IP 1100 页未封)。
