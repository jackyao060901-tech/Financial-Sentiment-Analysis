# 各平台爬取可行性报告

> 第一阶段目标:广泛摸清各金融社区平台**能不能爬、能的话怎么爬**,并做出能跑的采集原型。
> 本阶段**不做情绪分析**,但字段按"以后要做情绪分析"来设计(见 `docs/data_schema.md`)。
> 侦察日期:2026-07-04 ~ 07-05。测试环境为云端(出网走策略代理)。

## 执行摘要(给导师的一页结论)

- **共调研 10 个平台/入口,其中 5 个已做成可跑爬虫并采到真实带正文样本**:东方财富股吧、东方财富个股新闻、新浪财经股吧、同花顺个股资讯、淘股吧。
- **最推荐主攻东方财富股吧**:无需登录、字段最全(含阅读/评论/看涨看跌标记)、量大且用户全是散户,最贴合"散户舆情"目标。
- **雪球**:数据质量高但被**新版阿里云 WAF**保护,需真实浏览器过 JS 挑战;爬虫已写好,但**本云沙盒的浏览器无法联网**,需在普通网络机器上跑(已记录三种方法及各自局限)。
- **难/不可行的**:同花顺社区帖子(Vue SPA+签名接口)、微博(搜索需登录)、金融界/和讯(本环境不可达)。
- **数据真实性**:所有样本均为**真实抓取**,每条带 `url + crawl_time` 可回溯核对;拿不到的字段显式留空,不臆造。

## 1. 东方财富股吧(推荐首选)✅

- **入口**:`https://guba.eastmoney.com/list,{股票代码}.html`,分页为 `list,{代码}_{页码}.html`。
- **关键发现**:列表页静态 HTML 里内嵌一段 `var article_list = {...}` 的 JSON,**每页约 80 条**,直接 `json.loads` 即可,无需解析 DOM,非常稳。
- **能拿到的字段**:帖子 id、标题、作者昵称/ id、**发帖时间(带完整年份)**、阅读数(post_click_count)、评论数、转发数、是否含图/视频,以及平台自带的 `bullish_bearish`(看涨/看跌标记 —— 以后可当情绪的免费参照)。
- **正文**:列表里没有正文,需再请求详情页 `/news,{代码},{帖子id}.html` 抽取(爬虫里 `--with-body` 开关)。
- **登录/Token**:**都不需要**。
- **反爬**:低。带常规浏览器 UA 即可,请求间隔 1~2.5 秒足够礼貌。
- **代码**:`crawlers/eastmoney_guba.py`(已实测跑通,样本见 `data/samples/`)。

## 2. 雪球 ⚠️(已实测,记录多种方法与各自局限)

- **入口**:讨论接口 `https://xueqiu.com/query/v1/symbol/search/status?...&symbol=SZ000001&type=11`。
- **能拿到的字段**(过了 WAF 之后):帖子 id、正文(text,HTML)、作者、发帖时间(毫秒时间戳)、阅读/评论/转发数。
- **价值**:用户更专业、讨论质量更高,值得作为第二数据源。
- **核心障碍**:接口受**新版阿里云 WAF**保护。实测抓到的挑战页含 `aliyun_waf_aa/oo/00` meta 标签、混淆的 `_0x` 变量、一段用 `Function()` 动态执行的 JS,以及一大坨 base64 载荷 —— 属于**JS-VM 型挑战**(需在真实浏览器环境里执行才能拿到放行 cookie)。

下面记录三种方法及**各自的局限**:

### 方法一:真实浏览器自动化(Playwright)——**推荐**
- **原理**:用真实 Chromium 加载页面,像真人一样执行 WAF 的 JS 通过挑战,拿到有效 cookie 后再请求接口 / 解析 DOM。代码见 `crawlers/xueqiu.py` 的 `fetch_via_browser`(已做 Chromium 自动探测 + 代理配置 + 忽略代理 TLS)。
- **优点**:**稳**。WAF 怎么升级,真浏览器都跟着自动过,不需要我们反复破解。
- **局限**:
  1. 依赖能联网的浏览器,比纯接口重(要装 Playwright/Chromium)。
  2. **本云沙盒实测跑不通**:出网走策略代理,`requests` 能走代理,但 **headless Chromium 穿不过该代理**——连 `https://example.com` 都 `ERR_CONNECTION_RESET`。所以**在当前沙盒里采不到雪球样本**。
  3. 雪球反爬对频率敏感,易封 IP,必须低频。
- **怎么才能跑通**:在**普通网络的机器**(如本地电脑,浏览器可直连)上运行 `crawlers/xueqiu.py` 即可正常过 WAF 取样;或后续解决沙盒的"浏览器-代理"连通问题。

### 方法二:纯 requests(不执行 JS)——**不可行**
- **实测**:先访问首页拿到 `acw_tc` cookie,再请求接口,返回的**仍是 WAF 挑战页**(含 `aliyun_waf`/`_waf_`)而非数据。
- **局限**:requests 不会执行 JS,过不了 JS-VM 挑战,拿不到真数据。**此路不通。**

### 方法三:无浏览器执行挑战 JS / 逆向 WAF——**实测跑不通,不推荐**
- **做法**:不开完整浏览器,尝试用 JS 引擎(Node)或轻量 DOM(jsdom)执行那段挑战脚本,算出放行 cookie 后用 requests 重放。
- **实测结果**:
  - 裸 Node 直接执行 → 立刻报 `document is not defined`(挑战依赖浏览器 DOM)。
  - 用 jsdom 提供 DOM 后 → 挑战只执行了一部分(生成了 `window._waf_*` 变量),但**算不出放行 cookie**(`document.cookie` 为空),并卡在 `Not implemented: navigation to another Document`(挑战需要真实页面跳转)。
- **局限**:新版阿里云 WAF 依赖**真实浏览器导航 + 环境指纹**,jsdom 这类会被识破;要真做成,得对高度混淆的 JS-VM 做深度逆向,**工作量大、极脆弱**——阿里云一升级挑战就失效(与反爬的"军备竞赛"),得反复重做。**不推荐。**

### 小结
- **能采到数据的现实路径 = 方法一,在普通网络机器上运行。**
- 方法二不通;方法三理论可行但脆弱、且本环境实测未跑通。

## 3. 新浪财经股吧 ✅(已实测,做成可跑爬虫)

- **入口**:`http://guba.sina.com.cn/?s=bar&name={symbol}&page={n}`,`symbol` 形如 `sz000001` / `sh600519`(交易所前缀+代码)。
- **关键发现**:列表页是 **GBK 编码的静态 HTML**,帖子在一个表格里,每个 `<tr>` 一条,列为:阅读数 | 评论数 | 标题(链接)| 作者 | 时间。标题链接形如 `/?s=thread&tid={tid}&bid={bid}`(class 含 `linkblack`)。直接解析 HTML 即可,无需 JS。
- **正文**:在详情页 `/?s=thread&tid=&bid=` 的 `id="thread_content"` 容器里,需额外请求(`--with-body`)。
- **能拿到的字段**:帖子 id(tid)、标题、正文、作者昵称/id、阅读数、评论数、发帖时间、链接。
- **登录/Token**:**都不需要**。
- **反爬**:低。带常规 UA 即可,仍按 `polite_get` 控制频率。
- **注意**:① 页面是 **GBK**,须 `r.encoding="gbk"` 否则中文乱码;② 列表时间只有 "MM月DD日"(**不带年份**),已原样保留、不臆造。
- **代码**:`crawlers/sina_finance.py`(已实测跑通;样本 `data/samples/sina_sample.csv`,3 只股票各 8 条、全部带正文)。

## 4. 同花顺 ⚠️(已实测,分两块:资讯可爬、社区帖子难爬)

同花顺要分清两类内容:

### 4a. 个股资讯(文章)✅ —— 已做成可跑爬虫
- **入口**:公开 JSON 接口 `https://news.10jqka.com.cn/tapp/news/push/stock/?page={n}&code={code}`(code 为纯数字,如 000001)。
- **关键发现**:返回干净 JSON `data.list`,**无需登录/签名/token**。每条含 `title`、`digest`(摘要正文,内嵌可直接用)、`url`、`ctime`(秒级时间戳)、`source`。
- **局限**:是"资讯/文章"而非散户帖子,**没有阅读数/评论数**,情绪价值与股吧散户帖不同,但同属可用语料(导师原话含"帖子、文章")。
- **代码**:`crawlers/ths_news.py`(已实测跑通;样本 `data/samples/ths_news_sample.csv`,3 只股票各 8 条、全部带正文摘要)。

### 4b. 社区帖子(t.10jqka.com.cn/guba)⚠️ —— 偏难,暂缓
- **实测**:社区页是 **Vue 单页应用(SPA)**,帖子列表在静态 HTML 里是空的(`postlist-box` 容器由 JS 填充),通过 axios + 自研 `snsHttp` 接口异步加载,且引入了 `md5.min.js` —— 接口很可能**带签名**。
- **另**:老的 `guba.10jqka.com.cn/{code}/` 实测返回 **503**(反爬)。
- **可行路径**:用浏览器自动化(同雪球,沙盒里跑不了,需本地),或逆向其接口签名(脆弱)。**第一阶段暂缓**,先用上面的资讯接口。

## 5. 淘股吧 ✅(已实测,做成可跑爬虫)

- **入口**:个股页 `https://taoguba.com.cn/quotes/{symbol}`(symbol 形如 `sz000001`)。
- **关键发现**:个股页里 `class="related-subject"` 区是该股相关讨论帖,给出标题 + 文章链接(`https://www.tgb.cn/a/{id}`)。文章页可取:标题(`article-tittle`)、正文(`article-text p_coten`)、以及 `article-data` 区的**作者 / 发表时间(带年份)/ 浏览数 / 评论数**。字段比新浪更全。
- **登录/Token**:**都不需要**。
- **反爬**:低。
- **注意**:① `www.taoguba.com.cn` 证书异常,须用主域 `taoguba.com.cn`(文章域名为 `www.tgb.cn`);② 个股页每次约给出数条相关帖,**数据量不如股吧/新浪**,适合作补充源。
- **代码**:`crawlers/taoguba.py`(已实测跑通;样本 `data/samples/taoguba_sample.csv`,3 只股票各 6 条、全部带正文)。

## 6. 东方财富个股新闻 ✅(已实测,做成可跑爬虫)

- **入口**:公开 JSON 接口 `https://np-listapi.eastmoney.com/comm/web/getListInfo?client=web&biz=web_news&mTypeAndCode={mkt}.{code}&count={n}&type=1&order=1`(`mkt`:沪市 6 开头=1,深市=0)。
- **关键发现**:返回 `data.list`,每条含 `Art_Title` / `Art_ShowTime` / `Art_Url`;正文在详情页 `id="ContentBody"` 容器里(`--with-body` 抓取)。**无需登录/token**。
- **局限**:是东财的"资讯/文章"(与股吧散户帖互补),**无阅读/评论数**。
- **代码**:`crawlers/eastmoney_news.py`(已实测跑通;样本 `data/samples/eastmoney_news_sample.csv`)。

## 7. 微博财经 ⚠️(已实测,搜索需登录,暂缓)

- **实测**:`m.weibo.cn` 的访客 cookie(SUB/SUBP)可通过 `passport.weibo.com/visitor/genvisitor` → `incarnate` 流程拿到(**无需账号**),但用其请求个股关键词**搜索接口** `api/container/getIndex` 时,返回 `{"ok":-100, url:".../sso/signin"}` —— **搜索结果需要登录**。
- **可行路径**:需登录后的 cookie(涉及账号,反爬强、易风控);第一阶段暂缓。

## 8. 金融界 / 和讯股吧 ❌(本云环境不可达)

- 实测 `istock.jrj.com.cn`、`guba.jrj.com.cn`、`guba.hexun.com` 在本沙盒均**连接失败(代理 ConnectionError/ProxyError)** —— 可能被出网策略拦或站点本身变动。
- 结论:**本环境无法验证**;若在普通网络可达,二者多为传统 HTML 论坛,预计可爬,留待后续在本地核验。

## 数据质量与已知局限(诚实记录)

1. **样本是"原型级样本",非全量**:每个平台每只股票取十余条用于演示可行性与字段,不是完整采集;要做分析时再按需扩量。
2. **时间字段格式不统一**:多数平台带完整年月日时分,但**新浪列表仅"MM月DD日"(无年份)**,已原样保留、未臆造年份;跨平台合并分析时需先归一化。
3. **"资讯" vs "散户帖子"**:同花顺资讯、东财新闻是**文章/资讯**,没有阅读/评论数,情绪属性与股吧散户帖不同;分析时应区分对待。
4. **未做跨源去重与转载识别**:资讯类常有多站转载同一篇,后续分析前需去重。
5. **文本仅做轻清洗**:去 HTML 标签 / 解码实体 / 压空白;保留了 `$平安银行(SZ000001)$` 股票标记与 `[表情]` 占位符(是否清洗留待分析阶段按需决定)。
6. **易碎性**:网页结构/接口会变,爬虫需定期维护;已优先选用内嵌 JSON / 官方接口而非易变 HTML。
7. **合规**:仅研究/课程用途;所有请求带随机延时与失败重试(`common.polite_get`),控制频率、不影响目标站。
