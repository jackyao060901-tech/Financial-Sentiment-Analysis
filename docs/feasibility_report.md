## 二、研究价值对比(Research Utility:第三问,值不值得爬)

> **研究价值** ≠ **好爬**:新闻网站也很好爬,但它代表的是消息面,不是散户情绪。
> 对"投资者情绪分析"这个目标,**研究价值(对研究目标的适用性)**才是决定"值不值得爬"的关键。

**研究价值的评判依据(据以下因素综合判断,非主观拍脑袋):**
1. **是否主要由投资者产生内容**(UGC vs 机构/媒体转载);
2. **是否围绕具体股票展开讨论**(个股连续讨论,而非泛财经话题);
3. **是否持续、连续更新**(有稳定的日度信息流,便于按天聚合情绪);
4. **是否反映投资者观点**(原创观点/情绪,而非新闻转载);
5. **是否具有一定互动规模**(阅读/评论/点赞等,能反映热度与共识)。

> 例:东财股吧五项几乎全中(纯散户、围绕个股、日更、原创、互动多)→ 研究价值**高**;
> 资讯类多为新闻转载、无互动 → 对"散户情绪"研究价值**中低**,更适合做消息面。

| 平台 | 数据丰富度 | 研究价值(对散户情绪) | 适用场景 | 实采? |
|------|:---:|:---:|------|:---:|
| **东方财富股吧** | 高 | **高**(最能代表散户情绪) | 散户情绪、个股热门讨论 | ✅ |
| 淘股吧 | 较高 | 较高(游资/短线视角、深度帖) | 游资短线情绪、投资逻辑 | ✅ |
| 雪球 | 高(判断) | 高(判断,深度观点多) | 深度观点分析、投资逻辑 | ✖ |
| 微博财经 | 高(判断) | 较高(判断,传播力大) | 热点事件传播、破圈情绪 | ✖ |
| 同花顺·社区帖子 | 较高(判断) | 中(判断) | 散户情绪(备选) | ✖ |
| 新浪财经股吧 | 中偏低 | 中低(活跃度低,阅读数常个位数) | 有限,新闻跟帖 | ✅ |
| 东方财富个股新闻 | 中(资讯) | 中低(新闻面,非散户帖) | 新闻/消息面 | ✅ |
| 同花顺·个股资讯 | 中(资讯) | 中低(新闻面) | 新闻/消息面 | ✅ |
| 富途牛牛·资讯 | 低(仅标题) | 中低(资讯聚合,与上重叠) | 新闻/消息面 | ✅ |
| 百度贴吧 | 中(有互动数) | **低**(个股同名吧多为公司/产品话题:招聘、广告,**非炒股讨论**) | 基本不适用 | ✅ |

> 一句话:**东财股吧胜在"研究价值高 × 好爬 × 好维护"三者兼得**;雪球研究价值同样高,但被难爬+高维护拉低了优先级;资讯类好爬,但研究价值(对散户情绪)有限;**贴吧能爬但内容跑偏,研究价值低**。

## 三、选型结论:为什么最终主攻东方财富股吧

一句话:**东方财富股吧在"好爬 × 好维护 × 数据丰富 × 纯散户"四项上同时最优**,是投入产出比最高的主力源。

- **好爬**:列表页内嵌 JSON,无需登录、无需 token。
- **好维护**:数据以**内嵌 JSON** 提供(比解析易变 HTML 稳)、无需登录;**本次调研期间未见结构频繁变化**(基于当前观察,非对未来的保证)。
- **数据丰富**:标题、正文、作者、精确到秒的时间、**阅读数、评论数、转发数**,还自带 `bullish_bearish` 看涨/看跌标记(可作情绪的免费参照)。
- **纯散户 + 量大**:最贴合"散户情绪"这一研究对象。

**第二梯队**:淘股吧(游资/深度帖,字段全但量小)、雪球(质量最高但难爬+难维护,建议在本地用浏览器采,作为高质量补充)。
**资讯类**(东财新闻、同花顺资讯)作为"新闻面"补充,但注意它们不是散户帖。

## 四、平台特点对比(以后导师问"为什么选东财"时的依据)

> 标 [实采] 的特点有真实样本支撑;标 [判断] 的来自公开认知,尚无本项目样本佐证。

- **东方财富股吧** [实采]:全散户、评论多、热门帖多、时间精确、自带看涨看跌标记。噪音多(口水帖、复读),但**胜在量大、字段全、情绪浓**。
- **淘股吧** [实采]:游资/短线风格明显,长文与深度分析帖多(如"理想反转因子读书笔记"),字段全(含浏览/评论/带年份时间);但**单股相关帖数量少**,更像精选而非海量。
- **新浪财经股吧** [实采]:偏新闻讨论,**社区活跃度低**——实测帖子阅读数常为个位数(阅1、阅2),情绪信号弱于东财。
- **同花顺·个股资讯 / 东财个股新闻** [实采]:是**资讯/文章**而非散户帖,**无阅读/评论数**,适合做"新闻面",不适合直接代表散户情绪。
- **雪球** [判断]:用户质量高、长文多、投资逻辑丰富,是**质量最高**的一档;代价是反爬最重、维护成本最高。
- **同花顺·社区帖子** [判断]:有活跃社区,但走签名接口,采集与维护成本高。
- **微博财经** [判断]:体量与传播力最大,但搜索需登录、风控强。

## 五、逐平台:能不能爬 / 怎么爬 / 值不值得爬

### 东方财富股吧 ✅
- **能不能**:能,最推荐。
- **怎么爬**:列表页 `guba.eastmoney.com/list,{code}.html` 内嵌 JSON;正文去详情页。代码 `crawlers/eastmoney_guba.py`。(细节见附录 B)
- **值不值**:**最值**——好爬、好维护、字段全、纯散户。

### 淘股吧 ✅
- **能不能**:能。
- **怎么爬**:个股页取相关帖 → 文章页取正文与元数据。代码 `crawlers/taoguba.py`。
- **值不值**:**值**——游资/深度语料、字段全;但量小,作精选补充。

### 东方财富个股新闻 ✅ / 同花顺个股资讯 ✅
- **能不能**:能,都是公开 JSON。
- **怎么爬**:`eastmoney_news.py` / `ths_news.py`。
- **值不值**:**中等**——干净好爬,但属"资讯/新闻面",非散户帖;作补充。

### 新浪财经股吧 ✅
- **能不能**:能。
- **怎么爬**:GBK 静态表格 + 详情页。代码 `crawlers/sina_finance.py`。
- **值不值**:**一般**——好爬,但社区活跃度低、情绪信号弱。

### 雪球 ⚠️
- **能不能**:能,但**必须用真实浏览器过新版阿里云 WAF**(纯 requests 不行,无浏览器逆向实测跑不通)。
- **怎么爬**:Playwright 加载页面过 WAF 再取数据;代码 `crawlers/xueqiu.py`。**本云沙盒浏览器无法联网,需在本地/普通网络机器跑。**(三种方法实测见附录 A)
- **值不值**:**值得,但排第二**——数据质量最高,代价是最难爬 + 维护成本最高(WAF 常变)。

### 富途牛牛·个股资讯 ✅(可爬,但仅标题)
- **能不能**:能。个股页是 SPA,但服务端把首屏数据写进内嵌 `window.__INITIAL_STATE__`,其中 `stock_news.list` 即个股资讯。无需登录。
- **怎么爬**:解析内嵌 JSON。代码 `crawlers/futu_news.py`。
- **值不值**:**低**——列表**仅标题、无正文摘要**(正文需再解析 1MB 重型文章页),且是资讯聚合、与东财/同花顺新闻重叠。**保留原型,暂不纳入样本集**。

### 百度贴吧 ✅(能爬,但研究价值低)——一个"能爬≠值得爬"的实测案例
- **能不能**:能,但**换渠道才行**。网页端从本环境(数据中心 IP)访问个股吧列表返回 **403**;改走**手机 App 接口** `tiebac.baidu.com/c/f/frs/page` + 公开签名(参数排序拼接 `tiebaclient!!!` 取 MD5)后,`error_code:0`,正常返回帖子。→ **同一平台换个渠道(Web→App)就从 403 变可采**,这是"多渠道"思路的价值。
- **怎么爬**:App 接口 + 签名。代码 `crawlers/baidu_tieba.py`。字段全(阅读/评论/转发/时间/摘要)。
- **值不值**:**低,不推荐**。**实采后发现内容跑偏**:个股同名吧多是**公司/产品话题**——"平安银行吧"是信用卡广告/招聘、"贵州茅台吧"在卖酒、"宁德时代吧"在聊入职工资,**几乎没有炒股讨论**。→ 技术上能爬,但对"散户情绪"研究价值很低。**这正是"实采验证"的意义:用事实否定一个看似该做、实则跑偏的源。**

### 同花顺社区帖子 ⚠️ / 微博 ⚠️ / 金融界·和讯 ❌
- **同花顺社区**:Vue SPA + 疑似签名接口,难;暂缓。
- **微博**:访客 Cookie 可拿,但个股**搜索接口返回需登录**(`ok:-100`→sso);暂缓。
- **金融界 / 和讯**:本云环境**代理连接失败,不可达**;留待本地核验。

## 七、数据质量与已知局限(诚实记录)

1. **样本是"原型级"**:每平台每股十余条用于验证可行性与字段,非全量;共约 300 条真实样本(**6 平台 × 5 只股票**,几乎全部带正文,见 `data/samples/`;富途/雪球为原型,未纳入样本集)。
2. **实采 vs 判断要分清**:东财股吧/新浪/淘股吧/两类资讯为**实采验证**;雪球/同花顺社区/微博的丰富度是**判断**,未实采。
3. **时间格式不统一**:新浪列表仅"MM月DD日"无年份,已原样保留、未臆造;跨平台合并前需归一化。
4. **资讯 ≠ 散户帖**:两类资讯无阅读/评论数,情绪属性不同,分析时应区分。
5. **未做跨源去重/转载识别**;文本仅轻清洗(去标签/解码实体/压空白),保留股票标记与表情。
6. **易碎性**:见维护成本;WAF/签名类平台今天能跑不代表明天能跑。
7. **真实性保证**:所有样本真实抓取,每条带 `url + crawl_time` 可回溯;拿不到的字段留空不臆造。

# 附录 A:雪球 WAF 三种方法实测细节

雪球接口受**新版阿里云 WAF(JS-VM 挑战)**保护:挑战页含 `aliyun_waf_aa/oo/00` meta、混淆 `_0x` 变量、`Function()` 动态执行与 base64 载荷,需真实浏览器环境执行才能拿到放行 cookie。

- **方法一 · 真浏览器(Playwright)= 推荐**:真执行 JS 过挑战,**稳**(WAF 升级也自动跟上)。局限:本沙盒 headless Chromium 穿不过出网代理(连 `example.com` 都 `ERR_CONNECTION_RESET`),需本地/普通网络机器跑。代码 `crawlers/xueqiu.py`(含 Chromium 自动探测 + 代理配置)。
- **方法二 · 纯 requests = 不通**:不执行 JS,只拿到 WAF 挑战页(含 `aliyun_waf`/`_waf_`)。
- **方法三 · 无浏览器执行/逆向 WAF = 实测跑不通、不推荐**:裸 Node 报 `document is not defined`;jsdom 只跑一半、算不出放行 cookie、卡在需真实页面跳转;新版 WAF 靠浏览器指纹+导航,逆向极脆弱(反爬军备竞赛)。

# 附录 B:各平台解析技术细节

- **东方财富股吧**:列表页 `guba.eastmoney.com/list,{code}.html` 内嵌 `var article_list={...}`(每页约 80 条,大括号配平提取);字段含 `post_title/post_publish_time(带年)/post_click_count(阅读)/post_comment_count/bullish_bearish` 等;正文在详情页 `"post_content"` JSON 字段。
- **东方财富个股新闻**:`np-listapi.eastmoney.com/comm/web/getListInfo?...&mTypeAndCode={mkt}.{code}&type=1`(沪市 6 开头 mkt=1,深市=0);正文在详情页 `id="ContentBody"`。
- **新浪财经股吧**:`guba.sina.com.cn/?s=bar&name={sz/sh+code}` 为 **GBK** 静态表格(阅读|评论|标题|作者|时间),须 `encoding="gbk"`;正文在详情页 `id="thread_content"`。
- **同花顺个股资讯**:`news.10jqka.com.cn/tapp/news/push/stock/?page={n}&code={code}` 公开 JSON,`digest` 摘要内嵌。
- **同花顺社区帖子**:`t.10jqka.com.cn/guba/{code}/` 为 Vue SPA,`postlist-box` 由 JS 填充,走 axios + 自研 `snsHttp` 接口且引入 `md5.min.js`(疑签名);老 `guba.10jqka.com.cn` 返回 503。
- **淘股吧**:个股页 `taoguba.com.cn/quotes/{symbol}` 的 `related-subject` 取帖 → 文章页 `article-tittle`/`article-text p_coten`/`article-data`(作者/时间/浏览/评论);注意 `www.taoguba.com.cn` 证书异常,用主域。
- **微博**:`passport.weibo.com/visitor/genvisitor`→`incarnate` 可拿访客 SUB/SUBP,但 `m.weibo.cn/api/container/getIndex` 个股搜索返回 `{"ok":-100,url:".../sso/signin"}`(需登录)。
- **百度贴吧**:Web 端 403(疑封数据中心 IP);改用 App 接口 `tiebac.baidu.com/c/f/frs/page`,参数按 key 排序拼 `k=v` 再接公开常量 `tiebaclient!!!` 取 MD5 大写作 `sign`,POST 即得 `thread_list`(字段 tid/title/view_num/reply_num/agree_num/share_num/abstract/create_time)。
- **富途牛牛**:个股页 `www.futunn.com/stock/{code}-{SZ/SH}` 内嵌 `window.__INITIAL_STATE__`,`stock_news.list` 为个股资讯(id/title/time/url/source);列表无正文摘要,正文需再请求 `news.futunn.com/post/{id}`(1MB 重型页)。
